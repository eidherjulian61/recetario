# Recetario

Recetario Comfama en formato de página web autocontenida.

## Uso

Abre [`index.html`](index.html) en cualquier navegador. Incluye:

- Buscador de recetas por texto
- Filtro por libro
- Secciones plegables para navegar cómodamente

No requiere conexión a internet ni dependencias externas: todo el contenido está dentro del propio archivo HTML.
